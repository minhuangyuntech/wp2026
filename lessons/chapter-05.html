PHP 程式語言快速導覽

共 6 節 更新於 2026/05

WordPress 是以 PHP 撰寫的，要進入主題與外掛開發，PHP 是必備技能。本章將快速帶過 PHP 的核心語法，並介紹強大的 AI 助手 GitHub Copilot。

5.1 PHP 程式語言簡介

PHP 是廣受歡迎的伺服器端腳本語言，全球超過 70% 的網站使用 PHP，WordPress 即是最大的應用案例。

PHP 程式碼以 <?php ... ?> 包裹，執行在伺服器端，輸出 HTML 給瀏覽器。

5.2 變數與基本資料結構

PHP 變數以 $ 開頭：$name = 'WordPress';。

常用資料結構：字串、整數、浮點數、布林值、陣列 (Array) 與關聯陣列 (Associative Array)、物件 (Object)。

5.3 決策指令的應用

決策 (Conditional) 控制程式分支：if / else / elseif、switch、三元運算 $a ? $b : $c。

PHP 7 之後新增的 null 合併運算子 ?? 在 WordPress 中也很常用。

5.4 迴圈指令

PHP 提供 for、while、do...while、foreach 四種迴圈。

在 WordPress 中最常見的就是 The Loop：while ( have_posts() ) { the_post(); ... }，用於依序輸出文章。

5.5 函式的運用

函式 (Function) 是可重複使用的程式碼區塊：function name($arg) { return $value; }。

WordPress 內建大量函式如 get_the_title()、the_permalink()、wp_enqueue_script()，是開發必備。

5.6 GitHub Copilot 的安裝與使用

GitHub Copilot 是 AI 程式碼助手，可在 VS Code 中即時建議程式碼。

本節介紹如何在 VS Code 安裝 Copilot 擴充套件、登入 GitHub 帳號、啟用授權，並示範如何用註解引導 Copilot 撰寫 WordPress 函式。
