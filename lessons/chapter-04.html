WordPress 佈景主題基礎

共 3 節 更新於 2026/05

佈景主題 (Theme) 決定了你網站的外觀與排版。本章從使用者角度出發，介紹如何挑選、安裝與調整佈景主題。

4.1 WordPress 佈景主題

WordPress 佈景主題分為兩大類：Classic Theme（傳統 PHP 模板）與 Block Theme（支援 Full Site Editing）。

本節介紹官方主題目錄、付費主題市集 (ThemeForest 等)，以及挑選主題的關鍵指標：更新頻率、活躍安裝數、支援度與效能表現。

4.2 佈景主題編輯功能

後台「外觀 → 自訂」(Customizer) 提供即時預覽的視覺化編輯器，可調整網站識別、色彩、選單、小工具等。

Block Theme 則使用「外觀 → 編輯器」(Site Editor)，能直接在前台編輯 Header、Footer、Template。

4.3 動手調整佈景主題

本節透過「附加 CSS」面板，示範如何在不修改主題檔案的情況下，加入自己的 CSS 樣式覆寫，例如修改文字顏色、隱藏元素、調整間距等。

也會介紹 選單管理、小工具區域，以及如何上傳網站圖示 (Site Icon) 與標頭圖。
