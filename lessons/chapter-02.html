HTML / CSS / JavaScript 基礎

共 3 節 更新於 2026/05

在深入 WordPress 開發之前，必須先掌握網頁前端的三大支柱：HTML 負責結構、CSS 負責樣式、JavaScript 負責互動。本章帶你快速複習這三個語言。

2.1 HTML 基礎

HTML (HyperText Markup Language) 是建構網頁的標記語言，使用 <tag>...</tag> 的語法定義文件結構。

本節涵蓋常用標籤：<h1>~<h6>、<p>、<a>、<img>、<ul>/<ol>/<li>、<div>、<span>，以及 HTML5 的語意化標籤 <header>、<nav>、<main>、<article>、<footer>。

2.2 CSS 基礎

CSS (Cascading Style Sheets) 用於設定 HTML 元素的樣式：顏色、字型、版面、間距等。

本節介紹選擇器 (selector)、盒模型 (box model)、Flexbox 與 Grid 排版、響應式設計 (Media Query) 等核心概念。

2.3 JavaScript 基礎

JavaScript 是瀏覽器中執行的腳本語言，用於實作互動效果。

本節涵蓋變數 (let / const)、資料型別、函式、條件判斷、迴圈，以及最重要的 DOM 操作（document.querySelector、addEventListener）。
