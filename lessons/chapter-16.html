CHAPTER 16 · 高階 · 觀念

進階主題與活用 AI

共 3 節 更新於 2026/05

課程的最後一章，我們綜合討論 WordPress 的未來趨勢、實務上的網站維運，以及如何善用 ChatGPT 等 AI 工具加速開發。

16.1 WordPress 的演進趨勢

近年 WordPress 的重要變革：Block Editor (Gutenberg)、Full Site Editing (FSE)、Block Theme、theme.json、Interactivity API、Headless WordPress。

本節介紹這些趨勢的影響，以及作為開發者該如何因應。

16.2 網站備份、搬家與開發流程

備份工具：UpdraftPlus、Duplicator、All-in-One WP Migration。

搬家流程：備份 → 上傳到新主機 → 還原資料庫 → 修改 wp-config.php → 更新 site URL。

開發流程建議：本地開發 → Staging 測試 → 正式環境部署，搭配 Git 版本控制。

16.3 ChatGPT 活用術

ChatGPT 對 WordPress 開發的助益：產生外掛骨架、撰寫 hook 範例、解釋錯誤訊息、生成 CSS、撰寫文章草稿。

Prompt 撰寫技巧：明確說明 WordPress 版本、所需 hook、預期輸入輸出，並要求遵循 WP Coding Standards。

搭配 GitHub Copilot 在 IDE 內自動補全，能讓開發效率提升 2~3 倍。
