WordPress 外掛開發基礎

共 3 節 更新於 2026/05

外掛 (Plugin) 是擴充 WordPress 功能的標準方式。本章從零開始，帶你建立第一個自己的外掛。

11.1 WordPress 外掛入門

一個最簡單的外掛只需要一個 PHP 檔案，並在開頭加上 Plugin 標頭註解：/* Plugin Name: My Plugin */。

把檔案放到 wp-content/plugins/my-plugin/my-plugin.php，後台「外掛」頁面就能看到並啟用。

11.2 Hooks 簡介與應用

Hooks 是 WordPress 的擴充機制，分為兩種：

Action：在某個時機執行你的函式，例如 add_action('init', 'my_init')。

Filter：修改某個資料後再回傳，例如 add_filter('the_content', 'my_filter')。

理解 Hooks 是 WordPress 開發的核心技能。

11.3 使用外掛過濾文章的內容範例

本節以「在每篇文章末尾加上版權聲明」為例，示範如何使用 the_content filter 修改文章輸出。

完整外掛只需要約 15 行 PHP，是學習 Filter 的最佳起點。
