CHAPTER 01 · 基礎 · 觀念 + 實作

WordPress 的安裝與結構剖析

共 3 節 更新於 2026/05

本章將帶你建立對 WordPress 的整體認識，並動手在本地端安裝一套 WordPress 網站，最後深入剖析 WordPress 的目錄結構，為後續開發打下穩固的基礎。

1.1 WordPress 網站的基礎知識

WordPress 是目前全世界市佔率最高的 內容管理系統 (Content Management System, CMS)，依 W3Techs 統計，全球約 43% 的網站使用 WordPress。

本節介紹 WordPress 的歷史、開源 (GPL) 授權、WordPress.org 與 WordPress.com 的差異，並說明為什麼 WordPress 適合作為你的第一個網站平台。

1.2 在本地端安裝 WordPress 網站

本地端開發是學習 WordPress 最安全、最快速的方式。本節介紹如何使用 Local、XAMPP 或 Docker 建立本地 WordPress 環境。

完整步驟：下載安裝程式 → 建立站台 → 設定 PHP / MySQL 版本 → 完成 WordPress 安裝精靈 → 登入後台。

1.3 WordPress 網站結構分析

WordPress 安裝完成後，目錄裡可看到三個重要的子資料夾：wp-admin、wp-includes 與 wp-content。

其中 wp-content 是開發者最常接觸的資料夾，它包含 themes（佈景主題）、plugins（外掛）、uploads（媒體檔案）等子目錄。

另一個關鍵檔案是 wp-config.php，內含資料庫連線設定、加密金鑰、Debug 模式開關等重要配置。
