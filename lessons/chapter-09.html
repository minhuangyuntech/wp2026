CHAPTER 09 · 進階 · 實作

WordPress 佈景主題製作實例（下）

共 3 節 更新於 2026/05

延續上一章，本章深入探討 WP_Query 進階查詢、其他頁面模板的設計，以及多項主題開發的進階技巧。

9.1 WP_Query 類別探討

WP_Query 是 WordPress 中最強大的查詢類別，可依照分類、標籤、自訂欄位、日期等條件抓取文章。

範例：$q = new WP_Query(['category_name' => 'news', 'posts_per_page' => 5]);，搭配 $q->have_posts() 進入 Loop。

本節也會介紹 pre_get_posts 鉤點，用以修改主查詢而不破壞主題核心邏輯。

9.2 其他頁面模板的設計

本節介紹 archive.php、category.php、tag.php、single.php、page.php、404.php、search.php 等模板的撰寫要點。

也介紹「Page Template」機制，可讓使用者在後台為單一頁面選擇不同版型。

9.3 其他進階主題

進階技巧：自訂分頁 (paginate_links())、麵包屑、相關文章、Featured Image 縮圖大小註冊 (add_image_size())、enqueue 樣式與腳本的條件式載入。
