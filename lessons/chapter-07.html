CHAPTER 07 · 進階 · 觀念 + 實作

WordPress 所需的 PHP 程式設計技巧

共 3 節 更新於 2026/05

WordPress 核心與許多外掛大量採用物件導向設計。本章深入 PHP OOP 與 WordPress 主題顯示機制，是進入主題與外掛開發的必修課。

7.1 PHP 物件導向程式設計基礎

物件導向 (OOP) 三大特性：封裝 (Encapsulation)、繼承 (Inheritance)、多型 (Polymorphism)。

PHP 中以 class 定義類別，new 建立實例，$this 指向自身，:: 存取靜態成員。

7.2 PHP 物件導向程式進階

進階主題：抽象類別 (abstract)、介面 (interface)、Trait、Namespace、自動載入 (autoload)、魔術方法 (__construct、__get、__set)。

WordPress 核心類別如 WP_Query、WP_User、WP_Post 都是 OOP 的良好範例。

7.3 深入分析 WordPress 佈景主題的內容顯示

WordPress 透過「Template Hierarchy」決定要載入哪個模板檔案。例如造訪單篇文章會依序找 single-{post_type}.php → single.php → singular.php → index.php。

本節以圖表方式說明完整的模板層級，並透過 get_template_part()、get_header()、get_footer() 拆解模板。
